# -Sistema-de-Caixa-Eletrônico
Projeto acadêmico desenvolvido pelo Grupo 04 com o objetivo de aplicar conceitos de lógica de programação e estruturas condicionais utilizando Portugol e linguagem C.
Foram realizados testes práticos e todos tiveram seus resultados esperados.
Objetivo

Desenvolver um sistema que simula operações básicas de um caixa eletrônico, permitindo realizar saques, consultar o saldo disponível e calcular automaticamente as notas necessárias para cada retirada.

⚙️ Funcionalidades
Consulta de saldo disponível.
Realização de saques.
Validação de valores positivos.
Verificação de múltiplos de 5.
Verificação de saldo insuficiente.
Cálculo automático das notas entregues.
Menu para novas transações e encerramento.
🛠️ Tecnologias utilizadas
Portugol
Linguagem C
